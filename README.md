# wallet-
Закидываем все файлы в единую папку. Открываем файл main.pyw при помощи VS code, находясь внутри него открываем терминал. В терминале вводим команду "pyinstaller --onefile --noconsole --name "Wallet" --icon="icon.ico" --add-data "icon.ico;." main.pyw" для создания .exe файла. После успешного создания .exe файла открываем папку, в которой находились исходные файлы, там ищем и открываем папку dist, внутри нее запускаем Wallet.exe
